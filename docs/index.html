What It Does

A user-facing website operator path for design directions, runtime skins, receipts, and repo-native site evolution.

Site Profiles

Capture URL, local path, brand brief, constraints, stack hints, and allowed change modes.

Design Directions

Generate variants with design tokens, CSS, optional JavaScript, previews, and receipts.

Taste Memory

Record favorites, rejects, and more-like-this signals so the site evolves with the owner.

Deployable Outputs

Export reversible runtime skins or plan repo-native patches when the owner wants source changes.
